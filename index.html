Oriegano DevTools privacy policy

Effective date: November 22, 2026

Oriegano DevTools is a browser developer tool for reviewing security configuration in HTTP responses observed by the inspected tab. It processes data locally to display findings and suggested fixes. It does not require an account and does not send request data to the developer or to external services.

Data processed

While DevTools is open, the extension receives request metadata exposed by the browser's DevTools network API. It retains sanitized URL origins and paths, HTTP methods, response status codes, MIME types, and these response policy headers: Content-Type, Content-Security-Policy, Strict-Transport-Security, X-Content-Type-Options, X-Frame-Options, and Access-Control-Allow-Origin. URL credentials, query strings, fragments, request bodies, response bodies, authorization headers, and cookie headers are not retained by the capture state.

If you import a HAR file, the file is read and parsed on your device. HAR files can contain sensitive information. The extension reduces imported entries to the fields described above; it does not upload the file or its contents.

Purpose and retention

Data is used only to provide request analysis, findings, filtering, and reports. Live capture retains at most 1,000 requests in memory per DevTools window. Top-level navigation clears the live capture, and the Clear control discards captured data. Imported HAR review remains visible until cleared or replaced; closing DevTools discards the in-memory session. HAR imports are limited to 20 MB, with the newest 1,000 entries considered.

The extension does not use analytics, advertising, remote scripts, remote AI services, browser storage, or background browsing tracking. Its extension-page security policy disables network connections. Reload website asks the inspected tab to reload; the website's own requests remain subject to its privacy policy.

Exports and sharing

Reports are downloaded only when you select Export JSON. They contain origins, HTTP methods, status codes, rule findings, and report metadata. They omit URL paths, query strings, URL credentials, fragments, raw headers, and bodies. Origins and findings can still identify websites and reveal information about their configuration. Review reports before sharing them. Exported files remain on your device until you delete them.

The developer does not receive, sell, share, or transfer the request data processed by the extension. Data you voluntarily publish in an issue or send through another service is governed by that service's policies. Avoid including private URLs, credentials, HAR files, or reports in public issues.

Your controls

You can pause capture, clear the current session, close DevTools, remove exported files, or uninstall the extension. No developer-hosted data exists to request deletion of.

Limited use

Use of data received from browser APIs is limited to the extension's stated developer-facing purpose and follows the Chrome Web Store User Data Policy, including its Limited Use requirements.

Questions and changes

For privacy questions, use the developer contact shown on the extension's browser store listing. Do not include sensitive information in your message. If data handling changes, this policy will be updated with a new effective date.
